# Петрострой · Контент-Завод

Telegram-бот для генерации постов строительной компании из голосовых, фото и текстовых идей.

## Возможности (Фаза 1 — MVP)

- **Голос + фото** — Whisper → правка терминов → извлечение фактов → генерация поста
- **Своя идея** — текст → факты → генерация VK/TG/Shorts версий
- **9 рубрик** — видео-клип, планировка, страшилка, дом сдан, экспертиза, баттл, лайфхак, команда, статус
- **Review-кнопки** — опубликовать, переписать, сменить рубрику, выбрать фото, удалить
- **Статистика** — `/стат`, `/расходы` (для owner)
- **Контент-план** — `/план`

Публикация в VK на MVP — ручная (копипаст из бота). Фаза 2 добавит VK API и аналитику.

## Быстрый старт

```bash
cd petrostroy-content-factory
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните TELEGRAM_TOKEN, OPENAI_API_KEY, ANTHROPIC_API_KEY, INITIAL_USERS
python -m bot.main
```

## Настройка пользователей

В `.env` укажите Telegram ID и роли:

```
INITIAL_USERS=123456789:marketer:Дмитрий,987654321:foreman:Бригадир,111222333:owner:Владелец
```

Роли: `marketer` (полный доступ), `foreman` (только голос+фото), `owner` (просмотр + согласование + расходы).

## Команды бота

| Команда | Описание |
|---------|----------|
| `/старт` | Главное меню |
| `/идея [текст]` | Создать пост из идеи |
| `/рубрика` | Выбрать рубрику и сгенерировать |
| `/план` | Контент-план на неделю |
| `/стат` | Статистика постов |
| `/расходы` | Затраты на ИИ (owner) |
| `/готово` | Завершить добавление фото |

## Фазы разработки
